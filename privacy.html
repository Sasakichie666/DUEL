隐私声明 / Privacy Statement

适用站点：https://sasakichie666.github.io/DULEXS/　·　最后更新：2026-10

一句话总结：本站不收集、不上传、不出售任何个人信息。
没有账号系统、没有表单提交、没有 Cookie、没有统计与广告。

1. 本站不收集的个人信息

  • 姓名、邮箱、电话、住址等身份信息 —— 不收集
  • 账号、密码、验证码 —— 不收集。本站没有账号系统，也不需要你输入任何密码； 联机时输入的是房间号，仅用于把两名玩家牵上线
  • 位置、通讯录、相册、麦克风、摄像头等设备数据 —— 不请求、不访问
  • 支付信息 —— 本站完全免费，没有任何支付
  • 广告标识符、跨站追踪、用户画像 —— 不做

2. 只存在你自己浏览器里的数据（localStorage）

为了让设置下次打开还在，本站把下面几样东西保存在你自己的浏览器中。 它们不会离开你的设备，我们看不到、也无法读取：

键名内容用途
savedDeck你自己编辑的卡组下次打开时恢复卡组
responseIgnoreTimePoints响应连锁「忽略时点」的勾选记住你的响应偏好
卡组管理器筛选偏好类型 / 卡包筛选的勾选记住界面筛选状态

清除浏览器数据或使用无痕模式即可全部删除；这些内容不会同步到任何服务器。

3. 联机对战时会发生什么

  • 本站没有自己的服务器：对局数据只在两名玩家的浏览器之间 点对点（WebRTC）传输，不经过我们。
  • 为了把两名玩家牵上线，会使用第三方公共信令服务 PeerJS（0.peerjs.com） 以及浏览器内置的 STUN/TURN。该信令服务在建立连接时可能看到房间号与 建立连接所必需的技术信息（如 IP 地址 / ICE 候选），这些信息由该服务按其自身隐私政策处理； 我们既无法访问，也不存储相关记录。
  • 浏览器询问「允许暴露内网 IP」时，是否允许由你的浏览器决定； 它只用于让同一局域网内的两人直连更快，不会发送给我们。

4. 站点托管

本站托管在 GitHub Pages。作为托管方，GitHub 可能按自己的隐私声明记录标准的访问日志 （例如 IP、浏览器 User-Agent）。我们无法访问这些日志。

5. 第三方

本站不使用任何统计（Analytics）、广告、社交插件或追踪像素；不设置任何 Cookie； 不把任何数据出售或提供给第三方用于营销。

6. 儿童隐私

本站不收集任何用户数据，因此也不会收集儿童的个人信息。

Privacy Statement (English)

Applies to: https://sasakichie666.github.io/DULEXS/ · Last updated: 2026-10

Summary: this site does not collect, upload, or sell any personal information. There is no account system, no forms, no cookies, no analytics, and no advertising.

  • Not collected: names, email addresses, phone numbers, accounts, passwords, location, contacts, camera/microphone data, payment data, advertising identifiers, or any cross-site tracking. There is no login and no password is ever requested (the "room code" used for online play is only a short identifier for pairing two players).
  • Stored locally in your own browser only (never transmitted): your deck lists and two interface preferences, kept in localStorage (savedDeck, responseIgnoreTimePoints, and deck-builder filters). Clearing browser data removes them. We cannot read them.
  • Online play: matches run peer-to-peer over WebRTC directly between the two players' browsers. A third-party public signaling service (PeerJS cloud, 0.peerjs.com, plus public STUN/TURN) is used only to introduce the players; it may see the room code and the technical connection metadata (IP address / ICE candidates) required to establish the link, and handles it under its own privacy policy. Game data is never routed through any server of ours, and we keep no records.
  • Hosting: provided by GitHub Pages. As the host, GitHub may keep standard access logs (e.g. IP address, browser User-Agent) under its own privacy statement. We have no access to those logs.
  • Third parties: no analytics, advertising, social plugins, or tracking pixels are used; no cookies are set; no data is sold or shared for marketing.
  • Children's privacy: since no user data is collected at all, no children's personal information is collected either.
